# 巡检结果前端展示设计方案

## 一、目标

按照"巡检工具巡检结果.xlsx"格式展示巡检结果，数据获取来源明确，逻辑清晰。

  - network (可选): 网络名称筛选

## 六、后端数据来源（不修改代码，只说明）

### 6.1 数据来源说明

| 前端字段 | 数据来源 | 获取方式 |
|----------|----------|----------|
| seqNo | 后端生成 | 遍历时自增 |
| linkName | dmconnection表 | 缓存 `syncDataCache.getTableData("dmconnection")` |
| aNeName | dmne表 | 缓存 `syncDataCache.findById("dmne", neId)` |
| aNeTypeName | defdmne表 | 缓存关联查询 |
| aPortName | dmeo表 | 缓存 `syncDataCache.findById("dmeo", portOid)` |
| aModuleType | OpticalPowerInspection表 | SQLite查询 `powerRecordRepository.findByRoundId()` |
| aTxPower | OpticalPowerInspection表 | SQLite查询 |
| aRxPower | OpticalPowerInspection表 | SQLite查询 |
| aTxStatus | 门限计算 | ThresholdService.applyThresholds() |
| aRxStatus | 门限计算 | ThresholdService.applyThresholds() |
| aB1Error | 暂未实现 | 硬编码 "--" |
| aBandwidthUsage | BandwidthService | 查询带宽数据 |

### 6.2 数据获取顺序

```
1. 从 SQLite 获取巡检记录
   └─ optical_power_inspection 表（巡检结果）

2. 从缓存获取链路数据
   └─ dmconnection 表（cid=100）

3. 从缓存获取网元信息
   └─ dmne 表（网元名称、类型）

4. 从缓存获取端口信息
   └─ dmeo 表（端口名称）

5. 从缓存获取设备类型
   └─ defdmne 表（设备类型名称）

6. 计算门限状态
   └─ ThresholdService（越限判断）
```
